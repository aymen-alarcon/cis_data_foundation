# Corrected CMDB & CSDM practice bank

This revision restores all 20 previously excluded items to scored practice. Some items were **rewritten**, because their original wording or answer choices could not support a unique correct answer. These are concept-based replacements, not claims to reproduce the original exam questions.

## Q6: A CMDB Administrator is asked to clean up CMDB duplicates. What is the preferred way to manage this task?

**Correct answer:** The de-duplication dashboard on the CMDB Workspace

The De-duplication Dashboard in CMDB Workspace is the preferred central work area for reviewing duplicate CI tasks, viewing status, and applying templates to remediate similar duplicates in bulk. Individual de-duplication tasks and the Duplicate CI Remediator are also valid for resolving one duplicate set.

Documentation: https://www.servicenow.com/docs/r/servicenow-platform/configuration-management-database-cmdb/de-duplication-tasks.html

## Q12: Which two CMDB 360 saved-query insights show consolidated CI records and disagreements in attribute values between reporting sources? (Choose 2)

**Correct answer:** Unique Cls created from different data sources, Different attribute values from different data sources

CMDB 360 Get Records queries can display unique reconciled CIs from multiple reporting sources, while Compare Attribute Values queries reveal conflicting values reported for the same CI. The Find Gap query type can additionally identify source-coverage gaps, so this question focuses specifically on unique records and conflicting values.

Documentation: https://www.servicenow.com/docs/r/servicenow-platform/configuration-management-database-cmdb/cmdb360-exp-cmdb-workspace.html

## Q13: Where in CMDB Workspace can the team find de-duplication tasks generated by the IRE?

**Correct answer:** Important actions tile under Home

The Home view's Important actions tile includes de-duplication cards generated by IRE. Administrators can select the card to access de-duplication tasks and the dashboard for remediation.

Documentation: https://www.servicenow.com/docs/r/servicenow-platform/configuration-management-database-cmdb/cmdb-workspace-home-view.html

## Q14: A hardware CI has a warranty expiration date that Discovery cannot detect. How should the organization keep that attribute current?

**Correct answer:** Schedule imports of warranty dates from a trusted asset or vendor source

A scheduled import from a trusted asset or warranty system updates warranty expiration dates that Discovery cannot obtain. Creating a separate CI class does not keep those attributes current; IRE controls identification and authorized updates but is not itself the source of warranty information.

Documentation: https://www.servicenow.com/docs/r/servicenow-platform/configuration-management-database-cmdb/ci-class-manager-landing-page.html

## Q15: Which CSDM domain models relationships among infrastructure CIs, Technical Service Offerings, and Application Services?

**Correct answer:** Service Delivery (Manage Technical Services)

Service Delivery models the technical services, technical service offerings, application services and their supporting infrastructure. Service Consumption concerns services presented to consumers, not the technical dependency structure.

Documentation: https://www.servicenow.com/docs/r/servicenow-platform/common-service-data-model-csdm/csdm-enable-tso.html

## Q17: A CMDB administrator sees low scores on the CMDB Data Foundations Dashboard. Which two actions should they take? (Choose 2)

**Correct answer:** Use the remediation playbooks linked to affected metrics, Prioritize metrics marked Critical or High

Remediation playbooks describe concrete steps for investigating and fixing weak foundation metrics. Focusing first on Critical and High priority metrics addresses the greatest risk; excluding bad records merely to raise scores does not improve underlying data quality.

Documentation: https://www.servicenow.com/docs/r/zurich/servicenow-platform/configuration-management-database-cmdb/cmdb-data-foundations-dashboard.html

## Q25: The Change Management team in an organization wants to implement a Change across multiple Cls at the same time. Which field on the Change Request form needs to be populated with a dynamic Cl group?

**Correct answer:** Configuration item

Selecting a dynamic CI group in the Change Request Configuration item field expands its member CIs into the Affected CIs related list, enabling the change to target multiple CIs together.

Documentation: https://www.servicenow.com/docs/r/it-service-management/change-management/t_CreateAChange.html

## Q30: A Configuration Manager is implementing end to end service modeling and wants to get help on status and playbooks for improving the quality. What does the Configuration Manager reference to obtain guidance?

**Correct answer:** CSDM Data Foundations Dashboard

The CSDM Data Foundations Dashboard measures CSDM model adoption and service relationships and links to recommendations and playbooks. The CMDB dashboard instead concentrates on CMDB configuration and foundational data quality.

Documentation: https://www.servicenow.com/docs/r/servicenow-platform/common-service-data-model-csdm/csdm-data-foundations-dashboard-csdm.html

## Q49: The CMDB Administrator has been asked to establish Configuration Management with a functional CMDB. Which factor is most critical for successfully operationalizing the CMDB in ServiceNow?

**Correct answer:** Establish clear governance and continuously monitor CMDB health

Clear governance defines who owns CI data, how updates are authorized and how health is monitored. Discovery alone cannot enforce accurate ownership or remediation, while collecting excessive unmanaged data can make CMDB quality worse.

Documentation: https://www.servicenow.com/docs/r/servicenow-platform/configuration-management-database-cmdb/overview-cmdb-health.html

## Q66: A CMDB Administrator is using the Duplicate Cl Remediator to address a de-duplication task. On the first tab of the wizard, the Main Cl is selected. Which attributes are used to identify the Main Cl? (Choose 2 options)

**Correct answer:** Oldest Created, Most Related Items

The Duplicate CI Remediator recommends potential main CIs using criteria including Oldest Created and Most Related Items. The goal is to retain a reliable main record and preserve valuable references and relationships; these are two of several recommendation criteria.

Documentation: https://www.servicenow.com/docs/r/servicenow-platform/configuration-management-database-cmdb/reconcile-dup-task.html

## Q67: How is the CSDM and CMDB Data Foundations Dashboards application offered through the ServiceNow Store?

**Correct answer:** As a free application on the ServiceNow Store

ServiceNow describes the CSDM and CMDB Data Foundations Dashboards as a free ServiceNow Store application. In some releases the related plugin is activated by default, but that does not make the Store app a paid product or an Innovation Lab app.

Documentation: https://www.servicenow.com/content/dam/servicenow-assets/public/en-us/doc-type/resource-center/ebook/cmdb-business-value-6-steps.pdf

## Q68: Which activity best belongs to the CSDM Foundation domain?

**Correct answer:** Standardize foundational reference data such as organizations and locations

Foundation establishes the shared reference data and governance needed by the other CSDM domains, including consistent organizational, location and ownership information. This revised question tests the Foundation domain rather than treating the source's questionable role-matching table as an official rule.

Documentation: https://www.servicenow.com/docs/r/servicenow-platform/common-service-data-model-csdm/csdm-implementation-stages.html

## Q75: One Application Server hosts three different Applications, and each of those Applications is hosted only on that server. What is the cardinality from Application Server to Application?

**Correct answer:** One-to-many

From a single Application Server to its hosted Applications, one server can host several applications, giving a one-to-many relationship in that direction. A many-to-many relationship would require the additional fact that an application can be hosted on multiple servers.

Documentation: https://www.servicenow.com/docs/r/servicenow-platform/configuration-management-database-cmdb/c_ConfigurationManagementDatabase.html

## Q83: Which modules configure recommended fields and generate tasks when operational Linux servers lack Support Group or Managed by Group?

**Correct answer:** CI Class Manager and Health Preferences

CI Class Manager defines which CI fields are recommended for the Linux Server class. CMDB Health Preferences controls whether failed Recommended-field health checks generate remediation tasks, so both areas are needed.

Documentation: https://www.servicenow.com/docs/r/servicenow-platform/configuration-management-database-cmdb/overview-cmdb-health.html

## Q94: Which two Unified Map Content Controls change the scope of CIs shown on the map? (Choose 2)

**Correct answer:** Modify the number of relationship levels, Filter visible nodes using preferences or criteria

Unified Map Content Controls let users set relationship depth (number of levels) and apply filters or saved preferences to decide which CI nodes appear. Zoom is an appearance control in the Toolbox, not a content filter.

Documentation: https://www.servicenow.com/docs/r/servicenow-platform/unified-map/cmdb-workspace-unified-map.html

## Q96: What follows selecting Enable Life Cycle Sync?

**Correct answer:** Resolve incomplete mappings in Discrepancy Report

Selecting Enable life cycle sync runs a discrepancy check and generates a report of missing or inactive mappings. The administrator must resolve those mapping issues before bulk alignment can complete.

Documentation: https://www.servicenow.com/docs/r/servicenow-platform/common-service-data-model-csdm/csdm-life-cycle-standard-values.html

## Q110: Which property enables multisource CMDB?

**Correct answer:** glide.identification_engine.multisource_enabled

The exact system property glide.identification_engine.multisource_enabled is the main switch enabling CMDB 360/Multisource CMDB. The other properties govern more limited aspects of data capture or processing.

Documentation: https://www.servicenow.com/docs/r/servicenow-platform/configuration-management-database-cmdb/components-multisource-cmdb.html

## Q116: What do Health Inclusion Rules configured in CI Class Manager control?

**Correct answer:** Which CIs are evaluated by selected CMDB Health metrics

Health Inclusion Rules restrict the CIs evaluated by selected CMDB Health metrics, such as stale, orphan, or duplicate checks. They do not control which CIs IRE identifies: Identification Inclusion Rules are a separate feature used for that purpose.

Documentation: https://www.servicenow.com/docs/r/xanadu/servicenow-platform/configuration-management-database-cmdb/create-health-inclusion-rule.html

## Q188: Which table uses CI type to determine valid sublevel lifecycle states?

**Correct answer:** life_cycle_control

The life_cycle_control table determines which Life Cycle Stage Status values are permitted for a given Life Cycle Stage and type of CI. The Life Cycle Mapping table instead translates legacy status fields into the CSDM lifecycle model.

Documentation: https://www.servicenow.com/docs/r/servicenow-platform/common-service-data-model-csdm/csdm-lifecycle-logical.html

## Q189: Which role is typically responsible for administering CMDB configuration and CI data quality?

**Correct answer:** Configuration Manager / CMDB Admin

A Configuration Manager or CMDB administrator is responsible for governing CI data and administering CMDB processes and configurations. A CMDB Process Owner has process accountability but that title does not automatically grant the broadest platform permissions.

Documentation: https://www.servicenow.com/docs/r/servicenow-platform/configuration-management-database-cmdb/ci-class-manager-landing-page.html
